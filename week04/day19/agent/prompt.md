## Промпт:
В директории проект (подпапка "agent"), он представляет собой агента на python, который посылает запрос к API DeepSeek, механизм сжатия контекста, память агента (сессионная, рабочая, постоянная), профили, стэйт машина (FSM) с задачами, инварианты и его веб страница.

В папке "fortune-telling-mcp" - mcp сервис для доступа к API гадания по шару (Magic 8 Ball) и по книгам (Bibliomancy).

Необходимо сделать новый MCP-сервис, который будет раз в 2 минуты (конфигурируемый интервал) запрашивать евро (EUR) по отношению к доллару (USD)
Также есть задача на саммаризацию раз в 5 минут.

Результат должен разбираться и сохраняться в таблицу 

Требования к новому MCP сервису:
1. Kotlin стек
2. Хранение данных в SQLLite (.db файлы)
3. Поддерживаем валюты - евро и доллар
4. Транспорт - HTTP/SSE
5. сервис имеет 2 tool - 1) get_rate на текущее время 2) get_summary за указанную дату, возвращает { count, avg, trend, last_n }
Пример запроса:
curl -H "Authorization: Bearer art_live_LABUhxuLPMYJAfmiDp8XtfFAixZRkXXX" "https://allratestoday.com/api/v1/rates?source=USD&target=EUR"

Пример ответа:
[{"rate":1.13895,"source":"EUR","target":"USD","time":"2026-09-25T08:44:11+0000"}]

MCP интегрируется в основной агент. На вопросы типа - какой курс драма к рублю, должен отрабатывать tool, описанный выше.
