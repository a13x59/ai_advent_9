## Тестовый пример
Результат сравнения (10 вопросов × 2 повтора, reports/llm_comparison.md)
Бэкенд	Качество (0–2)	Скорость (ср.)	Ток/сек	Стабильность
local (llama3.1)	1.20	16.4 с (σ 6.3)	~20	20/20, 0 ошибок
cloud (DeepSeek)	1.45	2.6 с (σ 0.58)	~193	20/20, 0 ошибок
Выводы:

Качество — локальная модель отстаёт умеренно (1.20 vs 1.45). На 4 из 10 вопросов результат равен облачному (q9, q10 — по 2/2), на q4 локальная даже лучше (1.5 vs 1.0). Проседает в основном там, где нужен строгий формат «Ответ/Источники/Цитаты» и полнота перечисления фактов.
Скорость — облако быстрее ~6× (2.6 с против 16.4 с), ~193 против ~20 ток/с (CPU-инференс llama3.1 8B).
Стабильность — обе без единой ошибки; у локальной выше разброс времени (σ 6.3 с, эффект холодного старта/прогрева), но функциональных сбоев нет.

Замечание по стабильности: для честной оценки дисперсии я прогнал --runs 2; при --runs 3 σ будет надёжнее. Также учти, что RAG_LLM_PROVIDER/OLLAMA_* читаются из корневого .env — туда я ничего не дописывал (там уже были корректные OLLAMA_BASE_URL и OLLAMA_MODEL), локальный режим включается флагом.
