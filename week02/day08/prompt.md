## Ответ DeepSeek Harness:
Готово. Я расширил агента подсчётом токенов по трём метрикам и добавил слабейшую модель в список, не трогая остальную логику.

Что изменилось
main.py
 — подсчёт токенов
Добавил функции оценки токенов (estimate_tokens, estimate_messages_tokens) — приблизительный BPE-подсчёт без тяжёлых зависимостей (CJK-символы ≈ 1 токен/символ, слова ≈ 1.3 токена, пунктуация/эмодзи ≈ 1 токен). При этом, когда реальный DeepSeek возвращает usage, эталонные prompt_tokens/completion_tokens используются напрямую.

Теперь /agent возвращает в usage три новых поля:

request_tokens — токены текущего запроса (новое сообщение пользователя);
history_tokens — токены всей истории диалога (всё, что отправлено модели = prompt_tokens);
response_tokens — токены ответа модели (= completion_tokens).
Плюс оставлены прежние prompt_tokens/completion_tokens/total_tokens для совместимости. Мок-заглушка тоже переведена на эти функции (раньше был грубый len // 4).

index.html
 — отображение и список моделей
Панель статистики расширена: ⏱ Время · 📤 Запрос · 📚 История · 🤖 Ответ · 🔢 Всего · 💲 Стоимость.
updateStats() обновлён под новые поля.
В выпадающий список моделей добавлена deepseek-v4-flash — слабейшая (лёгкая «Flash»-версия) модель текущего API DeepSeek; deepseek-chat и deepseek-reasoner оставлены без изменений.
Проверка
