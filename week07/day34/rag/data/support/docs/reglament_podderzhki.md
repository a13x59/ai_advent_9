# Регламент службы поддержки

## Как устроена поддержка

Поддержка работает по тикет-системе: каждое обращение клиента регистрируется как тикет с уникальным номером. Тикет хранит тему, первое сообщение клиента, статус и, при наличии, данные покупателя. Номер тикета нужен, чтобы связать повторные обращения клиента в одну историю.

## Статусы тикета

Тикет может находиться в одном из статусов: `open` (новый, в работе), `pending` (ждём ответа клиента), `resolved` (решён), `closed` (закрыт). Новый тикет создаётся со статусом `open`.

## Приоритеты

Обращениям присваивается приоритет: `low`, `normal`, `high`, `critical`. По умолчанию тикет создаётся с приоритетом `normal`. Вопросы, связанные с невозможностью входа в аккаунт или с оплатой, обрабатываются в первую очередь.

## Ответ ассистента

Ассистент поддержки отвечает вежливо, по-русски и по существу, опираясь только на базу знаний и данные тикета. Если ответа нет в базе знаний, ассистент честно сообщает, что информации по вопросу нет, и предлагает уточнить запрос или связаться с оператором.

## Эскалация

Если вопрос требует участия человека (возврат денег, гарантийный случай, техническая проблема с аккаунтом), ассистент рекомендует написать оператору, указав номер тикета.
